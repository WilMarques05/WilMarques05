### 📂 Projeto em Destaque

#### 🚗 EliteDrive — Sistema de Gestão e Agendamento de Corridas
Aplicação web que simula uma plataforma de mobilidade urbana completa, desenvolvida durante o programa **Ford Enter (SENAI CIMATEC)** com **Angular 18+**.

- 🔗 **Repositório:** [github.com/WilMarques05/Agendamento-corridas](https://github.com/WilMarques05/Agendamento-corridas)
- ⚡ **Destaques Técnicos:**
  - **Arquitetura Angular:** Estruturada em *Standalone Components*, *Services*, *Guards* e *Reactive Forms*.
  - **Segurança & Controle:** Autenticação via *Firebase Authentication*, persistência de sessão e proteção de rotas com *Auth Guards*.
  - **Integração de APIs:** Mapeamento de rotas e geolocalização com *Google Maps API*.
  - **UI/UX & Otimização:** Interface responsiva com estética *Glassmorphism/Neon UI* e compressão automática de imagens via *Canvas API* antes do upload.
